content = """# Core Differences Between Type Aliases and Interfaces in TypeScript

In TypeScript, `type` aliases and `interface` are both used to define object structures, but they have some core differences between them. Below, the core differences are discussed:

## 1. Declaration Merging

If we declare multiple types with the same name, it will not merge and will throw an error. However, multiple interfaces with the same name will merge automatically.

```ts
type SalaryType = number;
type SalaryType = number;
// Will show error:
// Duplicate identifier 'SalaryType'.

// But interface will merge:
interface ISalary {
    salary: number;
}
interface ISalary {
    total: number;
}

const salary: ISalary = {
    salary: 1000,
    total: 2000
};
